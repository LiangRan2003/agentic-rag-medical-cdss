# ⚕️ 感染科辅助诊疗智能体 (Infectious Disease CDSS Agent)

基于大语言模型与多智能体协同 (Multi-Agent Workflows) 构建的垂直医疗领域 RAG 系统，旨在提供高度准确、无幻觉的临床决策支持 (CDSS)。

## 🌟 项目亮点

在严肃的医疗场景（特别是感染科用药指征严格的场景）中，传统的 RAG 系统容易因为检索不精准而导致大模型产生致命的“幻觉”。
本项目通过引入 **Agentic RAG（智能体化检索增强生成）** 架构，彻底解决了这一痛点：

1. **多智能体协同**：系统拆分为 Retriever Agent、Synthesizer Agent 和 Validator Agent。
2. **严苛的幻觉校验 (Hallucination Check)**：采用 LLM-as-a-Judge 机制，如果系统检测到生成的答案包含指南中不存在的捏造信息，将自动打回重做，确保输出 100% 具备溯源性 (Grounding)。
3. **高质量本地知识库**：内置多份最新版国家级医疗指南与共识（如《慢性乙型肝炎防治指南》、《中国社区获得性肺炎诊断和治疗指南》等），作为系统的金标准知识来源。
4. **流式状态可视化**：前端采用 Streamlit，动态展示 Agent 工作流的“思考过程”，使不可见的黑盒推理过程变得透明可信。

## 🏗️ 系统架构 (基于 LangGraph)

- **Retriever Node**: 利用本地部署的 BGE-m3 模型将临床指南文档向量化，存入 Chroma 数据库。接收用户输入后进行向量近似搜索。
- **Grade Documents Node**: 评估召回文档与用户问题是否高度相关，过滤无关噪音。
- **Generate Node**: 基于召回的高质量 Context 进行医疗回答的生成。
- **Hallucination Validator**: 条件判定边 (Conditional Edge)。对比生成结果与原始检索文本，判定是否产生幻觉。

## 💡 真实案例演示 (Case Study)

以下是系统基于加载的实体医学指南生成的真实问答示例，展示了模型强大的事实溯源和总结能力：

### 案例 1：慢性乙型肝炎的抗病毒治疗
**User:** 慢性乙型肝炎如何抗病毒治疗？

**CDSS Agent:**
> 根据《慢性乙型肝炎防治指南（2022年版）》，慢性乙型肝炎（CHB）的抗病毒治疗是降低相关并发症和肝细胞癌（HCC）发生率、提高患者生存率的最重要措施。治疗原则以更积极抗病毒治疗为导向，具体方案需根据患者病情阶段（如代偿期或失代偿期肝硬化）进行选择。
> 
> 以下是基于指南推荐意见的详细说明：
> 
> 1. **代偿期乙型肝炎肝硬化患者的抗病毒治疗**
>    - 推荐药物：优先推荐使用恩替卡韦（ETV）、替诺福韦酯（TDF） 或丙酚替诺福韦（TAF） 进行长期抗病毒治疗。
>    - 其他选择：若采用聚乙二醇干扰素-α（Peg-IFN-α） 治疗，需密切监测相关不良反应（如骨髓抑制、甲状腺功能异常等）。
>    - 证据等级：推荐意见为A1级（强推荐，高质量证据）。
> 
> 2. **失代偿期乙型肝炎肝硬化患者的抗病毒治疗**
>    - 推荐药物：推荐采用恩替卡韦（ETV） 或替诺福韦酯（TDF） 进行长期治疗。
>    - 禁忌：禁用聚乙二醇干扰素-α（Peg-IFN-α） 治疗，因其可能诱发或加重肝功能衰竭。
>    - 特殊情况：若必要，可以应用丙酚替诺福韦（TAF） 治疗（证据等级为B1级，中等质量证据）。
> 
> 3. **其他辅助治疗（非核心抗病毒治疗）**
>    指南同时指出，抗病毒治疗是核心，但可联合以下治疗以减轻肝脏炎症损伤：
>    - 抗炎、抗氧化、保肝药物：如甘草酸制剂、水飞蓟素制剂、多不饱和卵磷脂制剂和双环醇等。这些药物有助于减轻肝脏炎症坏死，但不能替代抗病毒治疗。
> 
> **总结**
> - **核心原则**：所有符合治疗指征的CHB患者（尤其是肝硬化患者）均应接受长期抗病毒治疗。
> - **首选药物**：口服核苷（酸）类似物（ETV、TDF、TAF）是肝硬化患者的一线选择。
> - **干扰素使用限制**：仅限代偿期肝硬化患者谨慎使用，失代偿期患者禁用。
> 
> 若您需要了解具体的治疗指征（如HBV DNA水平、转氨酶标准）或药物剂量调整方案，请提供更多临床信息，或参考指南原文。

### 案例 2：社区获得性肺炎的诊断标准
**User:** 社区获得性肺炎怎么诊断？

**CDSS Agent:**
> 根据《中国社区获得性肺炎诊断和治疗指南2025》，社区获得性肺炎（CAP）的诊断需结合临床表现、影像学检查和实验室检查进行综合判断。以下是基于指南的专业诊断要点：
> 
> 1. **临床诊断标准**
>    CAP的诊断主要依据以下核心条件（需同时满足）：
>    - 社区发病：患者在医院外（或入院后48小时内）出现肺炎相关症状。
>    - 临床表现：
>      - 新近出现的咳嗽、咳痰或原有呼吸道疾病症状加重，可伴或不伴脓痰、胸痛、呼吸困难、咯血。
>      - 发热（体温≥38℃）。
>      - 肺实变体征和/或湿性啰音（如听诊闻及支气管呼吸音、湿啰音等）。
>    - 影像学证据：胸部影像学（X线或CT）显示新出现的斑片状浸润影、叶或段实变影、磨玻璃影或间质性改变，伴或不伴胸腔积液。影像学是诊断CAP的必要条件，可排除其他类似疾病（如肺栓塞、肺癌、肺水肿等）。
> 
> 2. **鉴别诊断**
>    在确诊前需排除以下非感染性疾病：
>    - 肺结核、肺肿瘤、非感染性间质性肺病、肺水肿、肺不张、肺栓塞、肺嗜酸性粒细胞浸润症及肺血管炎等。
> 
> 3. **病原学诊断（辅助诊断）**
>    指南强调，对于重症CAP、经验性治疗无效或有流行病学风险（如耐药菌感染、特殊病原体暴露史）的患者，应积极进行病原学检查，包括：
>    - 常规检查：痰涂片及培养、血培养、尿抗原检测（如肺炎链球菌、军团菌）。
>    - 分子诊断：聚合酶链反应（PCR）检测呼吸道病毒、肺炎支原体、衣原体等。
>    - 特殊检查：支气管镜肺泡灌洗液培养、宏基因组二代测序（mNGS）等（用于疑难或罕见病原体）。
> 
> 4. **病情严重程度评估（辅助分层）**
>    诊断CAP后，需使用CURB-65评分或PSI评分评估病情严重程度，以决定治疗场所（门诊、住院或ICU）和抗菌药物选择。评分指标包括：
>    - CURB-65：意识障碍、尿素氮>7 mmol/L、呼吸频率≥30次/分、血压（收缩压<90 mmHg或舒张压≤60 mmHg）、年龄≥65岁。
> 
> **总结**
> CAP的诊断核心是：社区发病 + 典型临床表现（咳嗽、发热、肺部体征） + 胸部影像学新发浸润影。影像学是确诊的关键，病原学检查用于指导精准治疗。若患者符合上述条件，即可临床诊断为CAP，并启动经验性抗感染治疗。
> 
> 注意：本回答基于指南内容，若患者存在特殊情况（如免疫抑制、特殊暴露史），需结合个体化评估。如有疑问，请咨询临床医师。

## 🚀 快速启动

### 1. 环境准备
项目使用 Python 开发，建议使用虚拟环境：
```bash
python -m venv venv
source venv/bin/activate  # Windows: .\venv\Scripts\activate
pip install -r requirements.txt # (或根据源码中引用的 langchain 相关库自行安装)
```

### 2. 配置 API Key
在项目根目录创建 `.env` 文件，填入兼容 OpenAI 接口规范的 API Key（本项目默认使用高性价比的 DeepSeek）：
```env
DEEPSEEK_API_KEY="your_api_key_here"
```

### 3. 运行应用
```bash
streamlit run app.py
```

### 4. 加载知识库
首次启动后，请在网页左侧边栏点击 **“构建/加载向量数据库”**。系统将自动读取 `data/` 目录下的 PDF/DOCX 指南文件，并进行分块、向量化（耗时约1-2分钟）。后续使用将实现秒级加载。

## 📁 目录说明

- `app.py`: Streamlit 前端交互与入口文件。
- `src/workflow.py`: 基于 LangGraph 定义的多 Agent 工作流逻辑。
- `src/vector_store.py`: 本地文档读取 (PyPDFLoader/Docx2txtLoader) 与 Chroma 向量数据库构建逻辑。
- `data/`: 存放《诊疗指南》及《专家共识》等权威医学源文件。
